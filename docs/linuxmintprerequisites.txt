How to Fix Broken Sudo
One can use live USB to restore admin rights:
Boot broken computer into the live USB environment.
Open a terminal inside the live session (One automatically have root power here).
Find main system drive partition by running lsblk.
Look for main hard drive partition (e.g., /dev/sda2 or /dev/nvme0n1p2).
Mount broken system to a temporary folder:
bash
sudo mount /dev/sda2 /mnt
