necessary commands to resolve problems with build-essential install on Linux Mint 22.3 Zena

sudo apt-get install gcc-15 g++-15
sudo add-apt-repository ppa:ubuntu-toolchain-r/test
sudo apt update
sudo apt install gcc-15 g++-15
sudo apt install build-essential libgmp-dev libmpfr-dev libmpc-dev flex bison
sudo apt update
sudo apt install liblz4-dev
sudo apt-get install libsnappy-dev
sudo apt install libzstd-dev
sudo apt update
sudo apt install xterm

Notice for the systems with multiple USB: if your system is complicated,
remove downloaded *.iso files in all volumes, if it still stops in the grub menu when loading, call 'exit'.
